# 变更记录

## 1.0.0 — 2026-11-17

首个独立仓库发布，来源为 DevKit 主仓库 `6264ff6` 的 `examples/plugins/text-hex-responder`。

### 功能与兼容

- 保留插件 ID `devkit.text-hex-responder`、版本 `1.0.0` 及 DevKit 插件 API `1`。
- 保留文本完整行与 HEX 字节序列自动应答、跨接收批次匹配、单批多次匹配、手动发送和协议缓存重置。
- 保留回复换行、大小写、延时、缓存上限及单次接收最多 32 次回复的配置与行为。
- 不依赖 OA、DevKit 内部源码或串口原生模块。

### 独立维护结构

- 入口调整为 `src/index.cjs`。
- 测试迁至 `test/responder.test.cjs`，使用 Node.js 内置 `node:test`，可独立运行。
- 补充配置说明、目录安装与统一打包步骤。

### 修复

- 独立激活时执行与 manifest 一致的配置校验，拒绝非法模式、换行、数据类型、数值范围及未知字段。
- 超长未结束文本行丢弃至下一个换行符，避免把被截断行的后缀误当成完整匹配指令。
- 激活后使用独立配置快照，避免调用方修改配置对象影响正在运行的实例。

### 验证

- 增加文本/HEX 分批与粘包、换行边界、二进制数据、Unicode、缓存处理、手动动作、非法参数、延时取消、重复停止、洪泛限制及写入失败回归。
